# USD Search Explorer

USD Search Explorer is a sample reference implementation of a web application that provides an intuitive interface to connect to and interact with USD Search APIs. This web application serves as a reference implementation for users to build their own customized WebUI, demonstrating the capabilities of the USD Search API through a modern, user-friendly interface.

For more information on how to enable USD Search Explorer for your application please refer to [Helm chart documentation](https://registry.ngc.nvidia.com/orgs/nvidia/teams/usdsearch/helm-charts/usdsearch#sample-explorer-webui)
